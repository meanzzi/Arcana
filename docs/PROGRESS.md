- 다시 뽑기 연출: 지금은 결과 화면에서 바로 워싱부터 시작

## 구현하며 정한 것

- 카드 위치·기울기는 GSAP만 다룸 (인라인 style과 섞으면 React가 덮어씀)
- 슬롯은 `left`/`top`(테이블 기준 %)과 `rotation`으로 배치, 카드 자체 transform은 호버·뒤집기용으로 비움
- 시작 화면은 퇴장 후 더미 위치(`DeckOrigin`)를 넘기고, 22장이 그 자리에서 출발
- 흩어진 배치 각도는 -180~180도로 맞춤 (안 하면 카드가 몇 바퀴씩 돎)
- 단계 전환은 타이머 대신 완료 신호: `onWashEnd` → 부채꼴, `onFanEnd` → 잠금 해제
- 부채꼴 회전축은 모으기 끝난 0도 상태에서 바뀌어 모양이 튀지 않음
- 펼치기는 더미를 왼쪽 끝으로 옮긴 뒤 '손' 각도 하나로 오른쪽까지 쓸어 펼침 (가운데서 양쪽으로 갈라지지 않게)
- '동작 줄이기' 설정이면 움직임 없이 배치만 바꿈
- 코드 형식은 Prettier 기본 설정 (`.prettierrc.json`은 일부러 비워 둠)
