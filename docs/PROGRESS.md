## 구현하며 정한 것

- 카드 위치·기울기는 GSAP만 다룸 (인라인 style과 섞으면 React가 덮어씀)
- 슬롯은 CSS로 테이블 가운데(`left`/`top` 50%)에 두고 GSAP `x`/`y`(px)와 `rotation`으로 배치 (left/top 애니메이션은 모바일에서 렉). 카드(`.card`) transform은 호버·뒤집기용
- 뽑기 화면 구조: `DrawScreen`이 단계에 따라 `CardTable`(22장) / `ResultView`(결과)를 바꿔 보여줌. 애니메이션은 `useTableAnimation`·`useFanHover`·`useResultAnimation`, 배치 계산은 `utils/cardLayout.ts`
- 시작 화면은 퇴장 후 더미 위치(`DeckOrigin`)를 넘기고, 22장이 그 자리에서 출발
- 흩어진 배치 각도는 -180~180도로 맞춤 (안 하면 카드가 몇 바퀴씩 돎)
- 단계 전환은 애니메이션 완료 신호로: `onWashEnd`, `onFanEnd`, `onRevealEnd`, `onResultEnd`
- 흐름: start → scattered → fanned → revealing → result → dissolving → scattered. 뽑기·고르기·다시 뽑기 때 잠그고 각 애니메이션 끝에 풂
- `useGSAP`은 첫 단계 애니메이션을 다음 단계로 넘어갈 때 되돌림(배포 빌드에서만, 개발은 StrictMode가 가림). 그래서 각 단계는 시작 위치를 직접 정함
- 펼치기는 더미를 왼쪽 끝으로 옮긴 뒤 '손' 각도 하나로 오른쪽까지 쓸어 펼침
- 호버는 카드별 이벤트 대신 회전축 기준 각도로 포인터 아래 카드를 계산 (경계 떨림 방지)
- 호버 때 카드는 부채꼴 바깥쪽(사용자 쪽)으로 튀어나옴
- 카드는 앞·뒷면 두 겹. 뒤집기는 `.card`의 `rotationY` 180도
- 고른 카드는 결과 크기로 먼저 바꾸고 줄여 둔 뒤 1배로 키움 (작은 카드를 scale로 키우면 모자이크). 모서리는 `--card-radius`로 보이는 크기 유지
- 결과 화면 카드는 뒤집힌 카드의 화면 위치에서 출발해 위로 올라감 (결과 화면은 따로 그림)
- 카드 이미지: 원본 PNG는 `images/cards/`, 화면용 WebP(폭 840px, 품질 75, 장당 약 280KB)는 `public/images/cards/`
- 카드 이미지 23장(앞면 22 + 뒷면) 모두 들어감
- 참고 이미지는 `images/reference/` (배포 제외, git 제외)
- 이미지 파일이 없으면 불러오기 실패 시 회색 임시 카드로 대신함 (파일만 넣으면 코드 수정 없이 바뀜)
- 결과 카드는 `카드 뽑기`·`다시 뽑기` 때 미리 정하고(`nextResultRef`) 그 앞면 한 장만 미리 불러옴. 고를 때 드러냄
- 결과 화면 카드: `clamp(160px, min(70vw, 60dvh), 420px)`. 해석이 길면 스크롤
- 배경 반짝임: 4각 별 4개, CSS 애니메이션만. 위치·박자는 `StarField.tsx`의 `SPARKLES`
- 별자리 연출, 뒤집기 금가루 터짐, 해석 글자 등장은 넣지 않음 (화면이 바빠지고 글 읽기가 힘듦)
- 금박 틸트: 결과 카드가 다 올라온 뒤 켜짐. `quickTo`로 기울기와 반사 위치 CSS 변수(`--sheen-x/y/on`)를 따라감
- 금박 반사는 금색 계열 두 겹(동그란 빛 + 비스듬한 띠)을 `overlay`로 얹음. `Card`의 `children`이 앞면 위 효과 자리
- 디졸브: WebGL 직접 작성(`utils/dissolve.ts`). 카드 그림을 텍스처로 올리고 노이즈(fbm)+높이 값이 `progress`보다 낮은 픽셀을 버림, 경계는 금색. 2.6초 균일 속도
- 디졸브 중에는 앞면 위 캔버스가 카드를 대신 그림. 이미지 없는 카드는 회색 앞면을 2D로 그려 올림, WebGL이 없으면 흐려지며 사라짐
- 다시 뽑기 뒤 22장은 테이블 가운데에서 흐리게 나타나며 흩어짐
- 불러오기 실패한 이미지 주소는 기억해서, 새 카드는 처음부터 회색 임시 카드로 그림 (깜빡임 방지)
- 스크롤바는 숨김(스크롤은 됨). `html`에 배경색과 `overscroll-behavior: none` (아이폰 바운스 때 회색이 드러나지 않게)
- 모바일 틸트: 결과 카드는 `touch-action: none`이라 카드 위를 끌면 스크롤 대신 기울어짐. 스크롤은 카드 밖에서
- '동작 줄이기' 설정이면 움직임 없이 배치만 바꿈
- 코드 형식은 Prettier 기본 설정 (`.prettierrc.json`은 일부러 비워 둠)
- 코드 주석은 꼭 필요한 곳에만
