# Arcana of the Day – 디자인 시스템

> 어떻게 보이게 할지 정리한 문서. 화면 흐름과 기능은 `타로_기획서.md` 참고.

## 1. 원칙

- **밤하늘 정통 타로**: 짙은 남색 + 금박. 신비롭고 고전적인 느낌
- **덜어내기**: 남색 여백을 넓게, 금색은 몇 군데만 빛나게. 모든 요소가 똑같이 화려하면 카드가 묻힌다
- **위계**: 카드 → 제목 → 버튼 → 배경 장식 순서로 눈에 띄게
- **카드가 주인공**: UI는 카드 이미지의 틀(남색·금박)과 어울리게 하고, 카드 그림 속 색(빨강, 초록 등)은 UI에 쓰지 않는다

## 2. 색

| 토큰   | 색                   | 용도                              |
| ------ | -------------------- | --------------------------------- |
| 배경   | 짙은 남색 약 #141E3A | 화면 바탕                         |
| 금박   | 약 #C9A24A           | 테두리, 제목, 버튼, 별, 별자리 선 |
| 양피지 | 약 #E6D5A8           | 제목 리본, 본문 글자              |

- 값은 대략. 카드 이미지 틀에서 추출해 미세 조정
- 이 세 색과 그 투명도 변형 외의 색은 되도록 쓰지 않는다
- 배경은 단색보다 살짝 보라빛이 도는 남색 그라데이션 + 가장자리 비네팅

## 4. 시작 화면

모바일 세로 기준. 데스크톱은 같은 구성을 가운데 세로 영역에 두고 양옆은 배경만 확장.

- **위**: 리본 배너 안에 _Arcana of the Day_ (크게), 아래 한글 부제 (읽히는 크기)
- **가운데**: 카드 뒷면 더미, 크게. 뒤에서 은은한 금빛
  - 더미 뒤에 12궁 별자리 원을 **아주 흐리게** 배치, 천천히 회전
- **아래**: "카드 뽑기" 버튼. 꽉 찬 박스가 아니라 **금색 테두리선 + 금색 글자**로 가볍게
- **화면 테두리**: 네 모서리 장식 + 얇은 금색 선만. 안쪽에 아치형 틀을 또 넣지 않는다 (카드 안의 카드처럼 답답해짐)
- 위아래 여백 넉넉히

## 5. 배경 연출

- 은은하게 반짝이는 별
- 금색 선으로 천천히 그려지는 별자리
- 장식은 흐리게 처리해 뒤로 물러나 보이게

## 6. 모션

| 대상      | 효과                     |
| --------- | ------------------------ |
| 제목      | 금빛 광택이 한 번 지나감 |
| 카드 더미 | 숨 쉬듯 위아래로 둥실    |
| 버튼      | 은은하게 빛나는 펄스     |
| 별        | 반짝임                   |
| 별자리 원 | 아주 느린 회전           |

- 모션은 느리고 부드럽게. 신비로운 분위기 우선, 튀는 모션 지양
- 카드 관련 인터랙션(워싱, 펼치기, 호버, 뒤집기)은 기획서 4장 참고

## 7. 카드 표시

- 비율 **2:3** 고정. 이미지를 잘라내지 않는다 (틀이 이미지에 포함되어 있음)
- 모서리는 둥글게 잘라서 표시
- 앞면 이미지에 틀·숫자·이름이 있으므로 카드 위에 다른 장식이나 글자를 얹지 않는다
- 이미지는 가볍게 압축(WebP 등)하고 결과 공개 전에 미리 로드

## 8. 장식 요소 구현

화면 전체를 이미지 한 장으로 만들지 않는다. **장식은 이미지/SVG, 글자는 실제 텍스트, 배치와 움직임은 CSS.**

| 요소              | 방법                                          |
| ----------------- | --------------------------------------------- |
| 배경, 별, 빛 효과 | CSS                                           |
| 별자리 선         | SVG + CSS 애니메이션                          |
| 별자리 원         | SVG 또는 이미지 + CSS 회전                    |
| 금색 테두리선     | CSS                                           |
| 모서리 장식       | 장식 이미지 1개를 네 모서리에 회전 배치       |
| 제목 리본         | 리본 이미지 + 실제 텍스트                     |
| 카드 더미         | 실제 뒷면 이미지 여러 장을 살짝 어긋나게 쌓기 |
| 버튼              | CSS                                           |

- 모서리 장식과 리본 이미지는 **아직 없음** → 우선 CSS로 단순한 임시 장식을 만들고, 나중에 투명 배경 이미지로 교체할 수 있게 자리만 분리해둔다
