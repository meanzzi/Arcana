# Arcana of the Day – 디자인 시스템

> 어떻게 보이게 할지 정리한 문서. 화면 흐름과 기능은 `타로_기획서.md` 참고.

## 1. 원칙

- **밤하늘 정통 타로**: 짙은 남색 + 금박. 신비롭고 고전적인 느낌
- **덜어내기**: 남색 여백을 넓게, 금색은 몇 군데만 빛나게. 모든 요소가 똑같이 화려하면 카드가 묻힌다
- **위계**: 카드 → 제목 → 버튼 → 배경 장식 순서로 눈에 띄게
- **카드가 주인공**: UI는 카드 이미지의 틀(남색·금박)과 어울리게 하고, 카드 그림 속 색(빨강, 초록 등)은 UI에 쓰지 않는다

## 2. 색

| 토큰        | 색                           | 용도                                                    |
| ----------- | ---------------------------- | ------------------------------------------------------- |
| 배경        | #0B1433 → #15204A 그라데이션 | 화면 바탕                                               |
| 금박        | 약 #C9A24A                   | 테두리, 제목, 버튼, 별가루                              |
| 양피지      | 약 #E6D5A8                   | 제목 리본, 본문 글자                                    |
| 샴페인 골드 | #E8C77A / #D4A84B / #F3DFA2  | 금가루 입자, 카드 테두리·halo, 버튼 글자 등 빛나는 금색 |

- 값은 대략. 카드 이미지 틀에서 추출해 미세 조정
- 이 색들과 그 투명도 변형 외의 색은 되도록 쓰지 않는다. 보라·마젠타 계열 번짐, 순노랑(#FFD700 계열) 금지
- 배경은 단색이 아니라 짙은 남색(#0B1433)에서 살짝 밝은 남색(#15204A)으로 이어지는 그라데이션

## 4. 시작 화면

모바일 세로 기준. 데스크톱은 같은 구성을 가운데 세로 영역에 두고 양옆은 배경만 확장.

- **위**: 리본 배너 안에 _Arcana of the Day_ (크게), 아래 한글 부제 (읽히는 크기)
- **가운데**: 카드 뒷면 더미, 크게. 뒤에서 은은한 금빛 오라
  - 호버 효과 없음 (버튼과 헷갈리지 않도록 누를 수 있는 요소는 버튼 하나로)
- **아래**: "카드 뽑기" 버튼. 꽉 찬 박스가 아니라 **금색 테두리선 + 금색 글자**로 가볍게
  - 호버·터치 시 배경에 금빛이 은은하게 차오름
- **화면 테두리**: 선이나 모서리 장식 없이 미니멀하게. 배경과 카드에 몰입하도록 비움
- 위아래 여백 넉넉히

## 5. 배경 연출

- 짙은 남색에서 살짝 밝은 남색으로 이어지는 그라데이션
- 0.5~2px 흰색·연금색 잔별을 화면 전체에 흩뿌림 (정적). 대부분 아주 작고, 5% 정도만 더 밝고 크게
- 작은 흰색 4각 반짝임은 화면에 3~4개만, 천천히 은은하게 깜빡이는 정도
- 시작 화면에는 S자 금가루 띠: 오른쪽 위 → 카드 오른쪽 뒤 → 카드 아래를 감싸고 → 왼쪽 아래. 곡선에서 수직 방향으로 가우시안 분포로 흩뿌린 고운 입자 + 중심선을 따라 아주 옅은 금빛 광채. 가닥·빛줄기·꼬리 없이

## 6. 모션

| 대상      | 효과                                                                      |
| --------- | ------------------------------------------------------------------------- |
| 제목      | 금빛 광택이 한 번 지나감                                                  |
| 카드 더미 | 숨 쉬듯 위아래로 둥실 (대기 상태)                                         |
| 버튼      | 테두리를 따라 금빛이 천천히 회전 (CSS). 펄스는 버튼이 바빠 보여 넣지 않음 |
| 버튼      | 호버·터치 시 금빛이 배경에 차오름                                         |
| 금가루 띠 | 곡선을 따라 아주 느리게 흐르고 살짝 일렁임. 큰 입자만 각자 박자로 반짝임  |

- 모션은 느리고 부드럽게. 신비로운 분위기 우선, 튀는 모션 지양
- 카드 관련 인터랙션(워싱, 펼치기, 호버, 뒤집기)은 기획서 4장 참고
- 호버·배경 효과(십자 별 깜빡임, 버튼 호버)는 CSS로만 구현하며 퍼블리싱 단계에서도 예외적으로 먼저 적용함. 나머지(대기 상태 숨쉬기, 워싱 등 전환 애니메이션)는 애니메이션 단계에서 작업

## 7. 카드 표시

- 비율 **2:3** 고정. 이미지를 잘라내지 않는다 (틀이 이미지에 포함되어 있음)
- 모서리는 둥글게 잘라서 표시
- 앞면 이미지에 틀·숫자·이름이 있으므로 카드 위에 다른 장식이나 글자를 얹지 않는다
- 이미지는 가볍게 압축(WebP 등)하고 결과 공개 전에 미리 로드

## 8. 장식 요소 구현

화면 전체를 이미지 한 장으로 만들지 않는다. **장식은 이미지/SVG, 글자는 실제 텍스트, 배치와 움직임은 CSS.**

| 요소                     | 방법                                                                                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 배경 그라데이션, 십자 별 | CSS                                                                                                                                             |
| 잔별                     | Canvas (StarField, 정적. 화면 크기 바뀔 때만 다시 그림)                                                                                         |
| 제목 리본                | 리본 이미지 + 실제 텍스트                                                                                                                       |
| 카드 더미                | 실제 뒷면 이미지 여러 장을 살짝 어긋나게 쌓기                                                                                                   |
| 카드 더미 오라           | CSS 3겹: 넓은 후광 + 안쪽 코어 + 더미 halo(box-shadow), 동심원 안쪽 광원                                                                        |
| S자 금가루 띠            | Canvas: 베지어 곡선 수직 가우시안 분포 입자 8,000~15,000개로 형태를 만들고, 중심선에 옅은 금빛 광채(최대 불투명도 0.08)만 깔음 (시작 화면 전용) |
| 버튼                     | CSS                                                                                                                                             |

- 리본 이미지는 **아직 없음** → 우선 CSS로 단순한 임시 장식을 만들고, 나중에 투명 배경 이미지로 교체할 수 있게 자리만 분리해둔다
- 화면 테두리·모서리 장식은 미니멀한 방향으로 사용하지 않기로 함 (4장 참고)
