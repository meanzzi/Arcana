# Arcana of the Day – 기획서 (버전 1)

> 무엇을 만드는지 정리한 문서. 시각 규칙은 `타로_디자인시스템.md` 참고.
> 구현 방법(프레임워크, 라이브러리, 폴더 구조)은 이 문서를 바탕으로 따로 정한다.

## 1. 개요

- 카드를 섞고, 펼치고, 직접 골라서 뒤집어 보는 "오늘의 운세" 타로 웹앱
- 목적: 애니메이션·인터랙션 공부(화려한 인터랙션) + 가볍게 완성하는 개인 프로젝트
- 반응형 웹앱 (데스크톱 + 모바일)
- 백엔드 없음. 모든 데이터는 프론트엔드의 정적 파일로 관리

## 2. 버전 1 범위

**포함**

- 메이저 아르카나 22장 (0번 바보 ~ 21번 세계), 정방향 해석만
- 오늘의 운세 1장 뽑기
- 화면 2개: 시작 화면 / 뽑기+결과 화면
- 자동 워싱 셔플 → 모으기 → 부채꼴 펼치기 → 선택 → 뒤집기 → 해석 등장
- 다시 뽑기 (횟수 제한 없음, 워싱부터 다시 시작)
- 결과 링크 공유: 결과 화면 "공유하기" 버튼으로 휴대폰 기본 공유창을 띄움. 지원하지 않는 브라우저에서는 링크 복사

**제외**: 9장 참고

## 3. 화면 구성

### 화면 1. 시작 화면

- 앱 이름 **Arcana of the Day** + 한글 부제
- 가운데: 카드 뒷면 더미 (화면의 주인공)
- "카드 뽑기" 버튼
- 카드 앞면은 보여주지 않는다 (뽑았을 때 처음 공개)
- "카드 뽑기"를 누르면 **이 카드 더미가 그대로 흩어지며 워싱 시작**. 화면이 바뀌는 느낌 없이 이어지게

### 화면 2. 뽑기 + 결과 화면

화면 전환 없이 **한 화면 안에서 단계만 바뀐다.**

| 단계        | 내용                                                                                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ① 워싱      | 카드 22장이 뒷면으로 흩어져 자동으로 휘저어짐 (몇 초)                                                                                                                  |
| ② 모으기    | 가운데로 모여 한 더미가 됨                                                                                                                                             |
| ③ 펼치기    | 부채꼴로 펼쳐짐                                                                                                                                                        |
| ④ 선택      | 사용자가 한 장을 고름                                                                                                                                                  |
| ⑤ 뒤집기    | 선택한 카드가 가운데로 이동하며 뒤집힘                                                                                                                                 |
| ⑥ 해석      | 카드가 위로 올라가고 아래로 해석이 나타남. 표시 내용: 한글 이름 + 키워드 + 해석 문구 (번호·로마 숫자·영문명은 카드 이미지에 이미 있으므로 텍스트로 중복 표시하지 않음) |
| ⑦ 다시 뽑기 | 버튼을 누르면 ①부터 다시                                                                                                                                               |

## 4. 인터랙션 상세

### 워싱

- 실제 타로 리더가 카드를 테이블에 흩어놓고 양손으로 휘젓는 방식이 모티브
- 카드마다 위치·기울기가 랜덤하게 여러 번 바뀌고, 전체적으로 한 방향으로 살짝 도는 흐름
- 22장 전부 사용 (부채꼴에서 22장을 모두 펼치므로, 장수·크기가 단계마다 달라 보이지 않게)
- 자동 재생, 사용자 입력 없음

### 부채꼴 펼치기

- 22장 전부 펼친다 (사용자가 22장 중 한 장을 직접 고르는 단계)
- 모든 카드가 **위쪽 한 점을 축으로** 각도만 다르게 회전한 형태, 좌우 대칭. 카드 아래쪽이 사용자 쪽으로 벌어져(∪ 모양) 리더가 사용자 앞에 펼쳐 준 느낌
- 카드가 순서대로 펼쳐지는 시차 효과(스태거)

### 선택

- **데스크톱**: 마우스를 올린 카드가 **자기가 기울어진 방향으로** 살짝 튀어오름. 클릭하면 선택
- **모바일**: 손가락으로 카드 위를 문지르면 손가락 아래 카드가 튀어오르고, 손을 떼면 선택
- 튀어오른 카드는 옆 카드보다 앞으로 올라와야 함
- 카드 경계에서 두 카드가 번갈아 튀는 떨림이 없게

### 결과 배정

- 고른 위치와 무관하게 22장 중 한 장을 랜덤 배정
- 완전 랜덤. 직전에 나온 카드가 다시 나와도 막지 않음

### 뒤집기

- 카드는 **앞면·뒷면 두 겹 구조**
- 3D 회전 + 원근감
- 뒤집히기 전에 앞면 이미지가 미리 로드되어 있어야 함

### 입력 잠금

- 애니메이션 진행 중에는 카드 클릭/터치 막기
- 다시 뽑기 버튼 연타 방지

## 5. 카드 데이터 (JSON)

카드 22장 정보를 JSON 파일 하나로 관리.

| 항목         | 예시                             |
| ------------ | -------------------------------- |
| 번호         | 18                               |
| 로마 숫자    | XVIII                            |
| 이름(영문)   | The Moon                         |
| 이름(한글)   | 달                               |
| 이미지 경로  |                                  |
| 키워드 3~4개 | 불안, 직관, 환상, 무의식         |
| 정방향 해석  | 카드당 2~3개, 랜덤으로 하나 표시 |

- 해석 문구는 직접 작성해서 넣는다 (개발 중에는 임시 문구 사용)
- 나중에 역방향을 추가할 수 있게 "정방향 해석"으로 구분

## 6. 카드 이미지 (준비 완료)

- 앞면 22장 + 뒷면 1장, 비율 **2:3**
- 앞면 이미지에 틀, 로마 숫자, 카드 이름(영문·프랑스어)이 **이미 포함**되어 있음 → 코드로 틀이나 이름을 그리지 않는다
- 한글 이름은 이미지에 없음 → 해석 영역에 텍스트로 표시
- 뒷면은 22장 공통
- 파일 위치와 이름은 실제 파일 기준으로 맞출 것

## 7. 추천 개발 순서

단계마다 화면으로 확인하며 진행하고, 단계마다 어떻게 동작하는지 설명을 함께 받는다.

1. 프로젝트 세팅 + 밤하늘 배경 (정적)
2. 카드 컴포넌트 (앞뒷면 구조, 2:3, 실제 이미지 연결)
3. 부채꼴 펼치기 배치
4. 호버 튀어오르기 (데스크톱) → 문지르기 선택 (모바일)
5. 뒤집기 애니메이션
6. 해석 영역 등장 + JSON 연결
7. 워싱 → 모으기 → 펼치기 흐름 연결
8. 시작 화면 + 다시 뽑기
9. 입력 잠금, 모바일 반응형 점검
10. 배경 애니메이션 (별, 별자리)
11. 이미지 최적화 + 무료 호스팅 배포

## 8. 아직 정하지 않은 것

- 해석 문구 톤
- 시작 화면 한글 부제 최종 문구
- 기술 스택, 커밋 컨벤션, 파일 구조 → 프로젝트 세팅 때 결정
